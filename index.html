BGI graphics setup

Use C:\TURBOC3\BGI as your BGI driver directory, with graphics.h and GRAPHICS.LIB available in their bundled paths.

int gd = DETECT, gm;
initgraph(&gd, &gm, "C:\\TURBOC3\\BGI");

If you get “Graphics error,” verify the BGI path and that EGAVGA.BGI is present. Compile and link against GRAPHICS.LIB.

Common questions

Keyboard is not responding?

Click the DOS display to focus it. Press Shift+Escape to move focus back to the webpage.

How do I release or repair the mouse?

Press Escape to release pointer lock, or Shift+Escape to return focus to the page. If Turbo C stops accepting clicks after a menu, compile, or Help action, exit fullscreen with Escape and choose the Repair mouse button. It releases DOS mouse buttons and runs Turbo C's Repaint desktop command without restarting or losing your source.

How do I open uploaded .C files?

Press F3, clear the default *.CPP filter, then enter ..\PROJECTS\HELLO.C (substitute your filename). Press Enter. Restart first if a newly uploaded file is not visible.

How do I save my programs?

Press F2 in Turbo C, then open Files and select “Save locally.” Export files individually or as ZIP. Browser storage is device-local and can be cleared.
